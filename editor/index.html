      Icon Studio

      Workflow

      1. Draw a new icon, or open one from the library to edit it.
      2. Fill in the app name and package under App mapping.
      3. Fix anything red in the checks.
      4. Export → Glyph JSON and put the file in glyphs/.
      5. Push or open a pull request. CI validates it, scans it for malware, renders the icon and builds the APK. A release goes out after approval.

      Style

      • 24 × 24 grid, shapes inside the dashed square
      • 2-unit round strokes, flat colours
      • Cream lines, one orange accent
      • Draw what the app does, never its logo
